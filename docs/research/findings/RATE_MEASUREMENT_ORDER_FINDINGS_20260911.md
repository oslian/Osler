# Treatment records relative to current potassium draw

Timing-only audit; no future numerical outcomes read. Same expanded paired
queries. Current draw reconstructed from query minus current measurement age.
Only preceding6h insulin records, at or before query, considered.

3373 supported-sequence windows/1562patients:1065(31.6%) contain a rate record
after the current draw;554(16.4%) contain an observed rate change after it.
Current age median .45h; latest rate-record age median .50h. Hospital sequence
358windows/184patients:117post-draw records,43post-draw changes. Independent
patients in those smaller subsets not counted; do not infer adequate power.

Most prior sequence windows therefore do not directly test newly recorded
post-measurement changes. They test additional historical treatment summary
conditional on a more recent lab. This is a task-scope distinction, NOT proof
that treatment effects are fully absorbed by the lab or that earlier effects
cannot persist. Recording time is not proven administration/knowledge time.
Current draw time differs from result availability. No causal mediation claim.

This cannot explain every earlier failed target/JEPA test. A prospective-event
update test needs verified event timing and sufficient post-draw patient support,
not a posthoc assumption that all insulin windows are new interventions.
No fitting, runtime, interval or promotion change.
