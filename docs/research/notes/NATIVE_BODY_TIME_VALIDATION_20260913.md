# Validate Original History Before Masking

The body reconstruction wrapper masked target-only events before the trajectory
validated time. Four synthetic counterexamples (future, NaN, infinity, reversed
order in the removed event) were silently accepted. The new tests failed before
the repair and pass after validating the complete original stream first.

Fourteen reconstruction, trajectory and chronological replay tests pass. The
full original MAP cache was checked: 266,872 queries, zero empty/nonfinite/future/
non-strictly-ordered histories. Therefore this is a real contract defect, but
the inspected cache does not exercise it. It does not explain the preceding
MAP negative results and no accuracy improvement is claimed.

`scripts/audit_native_raw_time_contract.py`. Aggregate counts only.
