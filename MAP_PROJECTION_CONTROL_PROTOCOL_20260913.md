# MAP Projection Content Control

This is a training-matched diagnostic, not a proposed single-organ replacement.
Previous factorial training localized harm to expanded history, but did not
separate its observation content from activation cadence. Fixed-weight update
skipping and potassium memory-gradient probes do not answer this contrast.

Use the existing MAP native-query task and numeric-support control. At the
history observation projection only, replace other-variable numbers/masks/ages,
module presence and treatment fields with target-only native representation.
Preserve both clock coordinates, original active steps, temporal decay and
the complete current query. No extra parameters; same initialization, patient
draws, source transforms, 32 epochs, AdamW, EMA and source-tune selection.
Original clipped clocks are intentionally kept to match these references;
this is not deployment preprocessing. The separate clock-repair result remains
negative. No evaluation-based setting changes are permitted.

Compare against original own, full, and numeric support control, plus persistence.
First run fixed seed7 as integration/pilot, then the same six remaining seeds.
Patient-equal MAE and paired 20,000 patient bootstraps use existing definitions.
No pilot significance is a promotion. Reused hospital splits are not lockboxes.

Interpretation: improvement over control isolates a projection-content
intervention at unchanged cadence. Residual harm against own may involve
cadence or optimization, but cannot uniquely prove either because the query
and learned weights also differ. Mask/age/presence components remain grouped.
No gain is not proof that other organs lack information. The hook must be
explicitly reinstated to load this diagnostic checkpoint; never serve it as
an ordinary native filter. No release or interval changes.
