# Potassium component diagnosis

Use the seven selected whole weights from three-way source training. Reproduce
their evaluation predictions before intervention. Retain all own potassium
current/history values, masks, ages. Non-target source-supported variables only:
1. Numeric values -> normalized0, retaining masks/ages/presence.
2. Observed ages ->3hours, retaining numeric values/masks/missing ages.
3. Whole non-target block -> missing via existing support helper.

Compare each with unchanged full and separately trained own using same patients
and patient-level bootstrap1000. No retraining, no new external data, no
selection/deployment of any intervention. Artificial values can be off-manifold;
effects show learned dependence, not causal physiology or independent attribution
of medical workflow. No promotion and no unique-root-cause conclusion from this
small family of descriptive, unadjusted comparisons. Blood-glucose results from
the earlier component trial are not assumed to generalize to potassium.
