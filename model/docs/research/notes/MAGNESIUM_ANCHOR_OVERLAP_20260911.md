# Shared-future-outcome anchor comparison

Compared stored lag-tree predictions from original rate queries against Mg
availability queries, without refitting. Matched stay plus future source event
ID; future truth values match exactly. Multiple queries for one future outcome
are averaged as errors, then patients receive equal weight. This is descriptive
evaluation conditioning on future support, never a deployable routing rule.

Common hospital outcomes:81 events in49 patients. Source evaluation overlap:
92-124 events in58-69 patients per split. New whole-own incremental benefit is
significant0/7 in both common-outcome roles. The change in incremental benefit
from old to new is significant0/7 both roles. Thus the broad native-anchor
hospital near-miss cannot establish that timing alone repaired the model.
Support is smaller and inference remains uncertain; this is not equivalence.

Across all native hospital events, full-own mean error differences remain
negative in7/7, significant1/7. Leaving one patient out preserves the negative
mean in6/7; patient benefit fractions49.0-56.7%. The signal is not solely one
patient controlling every mean, but it is not a universal patient benefit.

Training samples, labels, and selection differ between anchor policies, even
on common test outcomes. No isolated causal timing effect or unique root cause
is proved. No model/threshold selection, calibration, runtime change or promotion.
