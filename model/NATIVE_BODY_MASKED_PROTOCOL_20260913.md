# Persistent Body Masked MAP Pilot

Use nested baseline excluded-patient pilot roles, retain anchor MAP age<=1h and
independent remaining history. Target/siblings fully removed including target-only
events. Same persistent body readout, initialized exactly at FIT median; eight
epochs real vs same-capacity patient-deranged contexts. Donors deranged within
each role independently, fixed without outcome selection, no self donors.
Source tune selects epoch0..8, patient paired bootstrap on previously inspected
evaluation/hospital roles. Report all exclusions/counts. No forecast/promotion.
This uses a previously future-paired cohort; not a representative missing-MAP
population, not independent validation of actual clinical missingness. Full
multi-target state utility and seven-seed validation remain outside this pilot.
