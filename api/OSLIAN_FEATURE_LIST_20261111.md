## 5. 第一版明確不做

| 項目 | 原因 |
|---|---|
| 臨床決策建議、劑量建議 | 證據只支持預測；`clinical_promotion_allowed: false` |
| 治療情境模擬 | `causal_claim_allowed: false` |
| ICU 以外的病人 | 沒有驗證證據 |
| 對外公開的雲端服務 | 會收到其他醫院的病人資料，且有訓練資料授權問題 |
| 床邊血糖預測 | 所有時間窗都未通過外部驗證 |
| 3D 人體視圖 | 只是呈現方式 |
| 聯合事件機率 | 邊際尾端未全部校準 |
